# Swingbus

The showcase page of Swingbus, an offline toolkit for grid-connection studies. The Grid Plotter benchmarks simulation results against field measurements; the Grid Calculator works out the grid behind a single-machine test.

Live at **[swingbus-present.vercel.app](https://swingbus-present.vercel.app/)**.

Swingbus is a personal project by two fresh electrical engineering graduates from Universitas Indonesia: Satria Wibawa Hadiwijaya ([taio11k.github.io](https://taio11k.github.io/)) and Devin Ezekiel Purba ([dvez373.github.io](https://dvez373.github.io/)). The app's code is private. This repository holds the page, its pictures and two demo videos.
